
# Microsoft Student Community @ USC

**Learn. Build. Connect.**

Welcome to the GitHub home of the Microsoft Student Community at the University of San Carlos, Cebu!

We're a student-led community focused on learning, building, and exploring technology through hands-on workshops, collaborative projects, and community initiatives.

## What We Do

- 💻 **Build:** Create practical software projects and tools.
- 📚 **Learn:** Share tutorials, workshop materials, and technical resources.
- ☁️ **Explore:** Experiment with cloud computing, developer tools, and Microsoft technologies.
- 🤝 **Collaborate:** Work with fellow students on projects that solve real problems.

## Get Involved

Whether you're a beginner or an experienced developer, there's room to learn and contribute.

1. Explore our public repositories.
2. Read the project's `README.md` and contribution guidelines.
3. Find an issue you'd like to work on.
4. Fork the repository or create a branch, then submit a pull request.
